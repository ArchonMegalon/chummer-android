Resources page off the UI thread and opens it directly. The consumed review is
removed from Back navigation. A fresh saved-state read must match the exact
confirmed draft, selections, snapshot and workspace revision. Owner transition,
page appearance and navigation stack are rechecked before continuation.

Continue. Confirmed cold recovery uses the same continuation. An uncertain save
remains fenced until explicit reconciliation of the existing command; a failed
read after reconciliation retains the saved-state fallback. No mutation budget,
rule calculation, package pin, signing control or provider permission changes.
Opening/retry copy is available in English, German and Spanish.
