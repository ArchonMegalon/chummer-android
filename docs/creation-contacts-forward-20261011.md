# Contacts: save and continue

A confirmed Contact add, edit or removal returns to the freshly admitted
Contacts list automatically. The user can add another contact or choose
**Continue to lifestyles**. Back no longer enters the consumed Contact editor,
review or old list. No contact, lifestyle or finalization is submitted implicitly.

The original owner transition stamp, workspace, content/saved revision, prepared
command and exact receipt still govern continuation. A failed read after a known
commit offers read-only continuation, not a second save. Unknown commit outcomes,
owner changes (including A→B→A) and retired appearances cannot advance or replay.
Saving/opening feedback stays visible; Lifestyles prepares its current authority
off the UI thread. Machine receipt details remain collapsed.
