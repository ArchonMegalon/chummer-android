# Single-read runner roster — 8 October 2026

The file-backed roster validates each saved runner once and projects its summary
from that same record. Other stores retain the established fallback. Generated
JSON metadata also covers the shared auxiliary contract, preserving canonical
digest bytes. This does not introduce cached documents, weaken owner admission,
or change strict continuation deserialization.
