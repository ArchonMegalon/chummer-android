Chummer Preview.12 is a candidate Internal testing build for phones. Current Preview authority covers exactly seven SR5 flows: Creation Prerequisite, Career Active Skill Advance, Career Weapon Fire, Before Run Edge, Playtime Short Burst, Downtime Calendar, and After Run Settlement.

CREATE THE COVERED START
Use the Creation Prerequisite flow to make the Priority selections and Resources choice exercised by the current phone test. Other visible creation stages are not claimed by this Preview authority.

ADVANCE AND PLAY
Advance one active skill, resolve one governed weapon-fire action, prepare Edge before a run, record a short Playtime Edge change, manage the Downtime calendar, or settle an After Run result. These are the six Career and table flows in the current Preview authority.

TRY EXPERIMENTAL ROUTES
Additional visible wizard routes remain available for feedback. Each is marked Experimental — not covered by the current Preview authority.

WORK LOCAL-FIRST
Open and save runner files you choose through Android's document picker. The app does not request broad storage access. Optional linked-account features use encrypted connections to Chummer services.

CURRENT PREVIEW LIMITS
This Internal testing preview is limited to the seven named SR5 phone flows. Full Editing, tablet or foldable support, SR4 or SR6 creation, Rook or live-avatar support, public availability, and production release are not included.

Chummer is a community character-management project. It is not an official tabletop game publisher app, does not include rulebook text, and does not replace the books required for play.
