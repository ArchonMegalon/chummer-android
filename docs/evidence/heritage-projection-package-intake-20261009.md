fields. Canonical metatype identity, attributes, movement and source digest are
read once per source element within one projection. Rank-specific calculations
remain separate and returned arrays are detached. Duplicate-field rejection,
owner stamps, source drift checks and mutation/persistence rules are unchanged.
No cache survives the read operation.
